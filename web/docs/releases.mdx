## Beta maintenance

<Admonition type="warning" title="Pre-v1 beta">

Expect instability and breaking changes between beta releases. APIs, CLI
commands, configuration, and storage schemas can change. Pin the version you
deploy and review the release notes before updating.

</Admonition>

Only the latest pre-v1 release receives fixes. Earlier beta snapshots stay in
Release History for reference. Once v1 ships, all beta releases are archived.

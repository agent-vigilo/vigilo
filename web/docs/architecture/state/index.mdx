# State

State diagrams for the database-backed lifecycle boundaries in Agent Vigilo.
Each <GlossaryTerm term="state">state</GlossaryTerm> changes through a guarded
<GlossaryTerm term="transition">transition</GlossaryTerm>.

The [dataset ingestion lifecycle](/docs/architecture/case-storage/ingestion#authority-and-publication)
covers upload staging, fenced publication, abort/expiry, and exact cleanup.

These views focus on:

- lifecycle states stored in PostgreSQL
- guarded transitions owned by CLI, coordinator, and worker processes
- <GlossaryTerm term="lease">leases</GlossaryTerm>, compatible row locks,
  <GlossaryTerm term="idempotent-operation">idempotent operations</GlossaryTerm>,
  and <GlossaryTerm term="no-op">no-op</GlossaryTerm> branches
- terminal outcomes that feed run status, gate status, and exportable evidence

A successful <GlossaryTerm term="claim">claim</GlossaryTerm> grants temporary
authority. Protected mutations validate a
<GlossaryTerm term="fencing-token">fencing token</GlossaryTerm> so an expired
or replaced owner cannot write stale state.

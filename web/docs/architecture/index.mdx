# Architecture

Agent Vigilo is a distributed AI evaluation runtime built around durable state,
explicit worker and coordinator ownership, isolated Wasm evaluators, and
retry-safe event publication.

The <GlossaryTerm term="vigilo-cli">CLI</GlossaryTerm> runs direct commands and
the <GlossaryTerm term="coordinator">coordinator</GlossaryTerm> and
<GlossaryTerm term="worker">worker</GlossaryTerm> service modes. The
<GlossaryTerm term="control-database">control database</GlossaryTerm> owns
global authority, while <GlossaryTerm term="execution-database">execution databases</GlossaryTerm>
own shard-local work. RabbitMQ is the
<GlossaryTerm term="broker">broker</GlossaryTerm> between coordinators and
workers.

# Context

Engineers and automation use the CLI. Rust applications embed the public library
and call the same operations in process, supplying their own runtime and
presentation. Both interfaces use the same durable execution workflows.
Vigilo calls the target through Direct Probe or sends case input to a Delegated
Trial harness that drives the session with the target.

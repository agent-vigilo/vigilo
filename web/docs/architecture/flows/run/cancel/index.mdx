Each placement commits terminal chunk receipts with cancellation, preserving committed results and retiring unfinished authority. Undispatched shards obtain snapshots from their frozen local run context. Coordinator pages subsequently publish progress and seals; the control lifecycle remains `cancelled`. Cancellation retry and fanout behavior are unchanged.

# Run Results Command

How `vigilo run results` loads a run and returns a summary-only results response.

Results include execution aggregate counts and the authoritative run scorecard. The scorecard reports each configured dimension or evaluator gate with coverage, mean score, pass rate, error rate, abstention rate, and failure reasons. A completed run can still have `gate_status: fail`.

Summary reads batch routed shards by execution database and merge them in shard
order, keeping floating-point scores independent of database grouping. Exports
use the same summary projection.

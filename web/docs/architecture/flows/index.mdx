# Command Flows

Step-by-step <GlossaryTerm term="command-flow">command flows</GlossaryTerm>
show how Vigilo commands move through runtime decisions and persistence
boundaries.

For lifecycle and database guard views, see [State Management](/docs/architecture/state/).

A <GlossaryTerm term="coordinator-cycle">coordinator cycle</GlossaryTerm> is
split into bounded <GlossaryTerm term="coordinator-pass">passes</GlossaryTerm>.
State changes create
<GlossaryTerm term="outbox-event-record">outbox event records</GlossaryTerm>
that publish as <GlossaryTerm term="broker-message">broker messages</GlossaryTerm>;
each <GlossaryTerm term="worker-delivery">worker delivery</GlossaryTerm>
identifies a chunk to claim.

[Setup](./setup/index.mdx) covers migrations, core collection discovery, and
idempotent evaluator installation.

# Worker Once Command

How `vigilo worker once` processes at most one chunk-ready broker message and exits.

Workers read assigned case batches through a shared, bounded immutable-byte cache
and fetch misses through the [storage adapter](/docs/architecture/case-storage/).
Every use verifies complete files and exact membership before execution evidence
is persisted in the routed database. [Run Preparation](/docs/architecture/case-storage/run-preparation)
describes cache ownership, limits and failure handling.
